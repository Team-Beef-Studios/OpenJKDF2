================================================================
 JKDF2-XR  -  Star Wars: Jedi Knight Dark Forces II in VR (PCVR)
================================================================

This is a PCVR (OpenXR) build of OpenJKDF2. It works with SteamVR,
Oculus/Meta, and other OpenXR runtimes.

You need a legal copy of Jedi Knight: Dark Forces II to play. No game
assets are included here. The GOG release is recommended (DRM-free and
includes the soundtrack).


----------------------------------------------------------------
 1. Copy your game files into THIS folder
----------------------------------------------------------------

From your Jedi Knight: Dark Forces II installation, copy the following
into this folder (next to jkdf2xr.exe), merging with what's already
here:

    JK.EXE
    episode/          (JK1.GOB, JK1CTF.GOB, JK1MP.GOB)
    resource/         (Res1hi.gob, Res2.gob, jk_.cd, video/)
    player/
    MUSIC/            (optional - the soundtrack, if you have it)

Note: a "resource" folder already exists here (it holds the renderer's
shaders and UI). Just merge your game's resource folder into it - keep
both sets of files.

When you're done, this folder should contain both jkdf2xr.exe and
JK.EXE side by side.


----------------------------------------------------------------
 2. Put on your headset and launch
----------------------------------------------------------------

Make sure your VR runtime is running (SteamVR, Oculus app, etc.), then
double-click:

    Play-JKDF2-XR.bat

The game should appear in your headset in stereo 3D.

Play-JKDF2-XR.bat checks which games you copied in. If you only have
Dark Forces II, it starts that game at once. If you also added
Mysteries of the Sith, it asks you which game to start.

You can still run jkdf2xr.exe directly if you prefer.

If nothing builds in the headset, confirm your OpenXR runtime is active
(in SteamVR: Settings > OpenXR > "Set SteamVR as OpenXR runtime").


----------------------------------------------------------------
 3. Mysteries of the Sith (optional)
----------------------------------------------------------------

The expansion is a separate game with its own assets, so it lives in
the "mots" folder rather than merging with Dark Forces II. You need a
legal copy of it too.

From your Mysteries of the Sith installation, copy into "mots":

    Episode/          (JKM.GOO, JKM_KFY.GOO, JKM_MP.GOO, JKM_SABER.GOO)
    Resource/         (JKMRES.GOO, JKMsndLO.goo, JK_.CD, VIDEO/)
    MUSIC/            (optional)

Then run Play-JKDF2-XR.bat and select Mysteries of the Sith. To start
it without the menu, run:

    jkdf2xr.exe -motsCompat

Dark Forces II and Mysteries of the Sith keep separate settings,
saves and weapon alignment - switching between them changes nothing
in the other.


----------------------------------------------------------------
 Notes
----------------------------------------------------------------

- jkdf2xr_vr_weapons.json contains pre-tuned VR weapon alignment.
  Keep it - it places the weapons correctly in your hand.
- If the game fails to start with a missing-DLL error, install the
  "Microsoft Visual C++ Redistributable (x64)" from microsoft.com.
- Controls are documented in the project's VR_CONTROLS.md.
- See the version marker file in this folder (JKDF2-XR-vX.Y.Z.txt) to
  check which build you have.
